SAKSHI POOJARY — PERSONAL PORTFOLIO

FILES
- index.html: website content
- style.css: dark theme and responsive layout
- script.js: mobile navigation menu
- profile.jpg: add your own portrait photo with this exact filename

BEFORE PUBLISHING
1. Add your portrait photo to this folder and name it profile.jpg (JPG/JPEG recommended). The photo appears in the hero section. If your photo has another extension, either convert it to JPG or update the src in index.html.
2. Open index.html and replace saakshipoojary68@gmail.com with your actual email address.
3. Replace https://www.linkedin.com/ with your personal LinkedIn profile URL.
4. Replace https://github.com/ with your personal GitHub profile URL.
5. Review the skills listed and keep only skills that represent your current experience.
6. Confirm the StudyPlanner project link is correct.

TEST LOCALLY
Open index.html in a browser. For easiest editing, open the folder in VS Code.

PUBLISH WITH GITHUB PAGES
1. Create a new public repository on GitHub, for example: saakshi-portfolio.
2. Upload index.html, style.css, and script.js to the repository root.
3. Go to repository Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose main and /(root), then Save.
6. Wait for the deployment, then open the displayed live URL.
7. Test the URL on your phone and make sure the links work.

Note: Google Fonts requires an internet connection; the site still works without it using fallback fonts.
